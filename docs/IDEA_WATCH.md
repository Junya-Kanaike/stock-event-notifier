# SNS投資アイデア監視（idea_watch）

YouTubeの指定チャンネルと、Notionの「アイデア受信箱」に放り込んだX投稿・YouTube動画・メモを1日2回（JST 07:13 / 16:13）処理し、イベントドリブン型の戦略アイデアだけを抽出してNotionの「投資アイデア」データベースに蓄積します。既存のイベント通知とは状態・実行枠を共有しません。

標準構成は**追加料金なし**（Gemini API無料枠＋GitHub Actions＋Notion）です。X APIとClaude APIは任意の有料オプションです。

## 何を拾い、何を捨てるか

`src/idea_watch/extractor.py` の `SYSTEM_PROMPT` が判定基準です（Gemini・Claudeどちらで抽出しても同じ基準）。Notionの戦略メモ（PO・分売・CB・第三者割当・指数除外・分割・TOB等の検証記録）から読み取った作り方をそのまま条件にしています。

- 拾う: 日付の決まった需給イベント、指数の除外・組入れ・リバランス、連動銘柄の乖離を取るロングショート、参加者行動の癖、指標の閾値シグナル、時期の決まったカタリスト付きの大型テーマ資金循環。きっかけ・需給上の理由・過去事例での検証可能性の3つがそろうもの。
- 捨てる: 決算予想・受注残・割安割高・目標株価・成長ストーリー、決算プレー、理由のない推奨、S高狙い・小型仕手、市況の感想。

各行には戦略タイプ、ロング側／ショート側、トリガー、予定日、エントリー、エグジット、需給メカニズム、検証方法、再現性、注意点が入ります。発信者が売買タイミングを語っていない場合、AIが補った案には「（補足）」が付きます。

## 仕組み

```
① Notion「アイデア受信箱」（自分で見つけた投稿・動画・メモ）
     X投稿URL   → X公式oEmbed（認証不要・無料）で本文取得
     YouTube URL → 動画URLのまま
     メモのみ   → そのまま
② Notion「監視ソース」
     YouTube → RSSで新着検知 → 動画URLのまま
     X / X検索 → X API（有料オプション。未設定ならスキップ）
        ↓
Gemini API（無料枠）: 動画は「視聴＋抽出」を1リクエスト、テキストは20件まとめて1リクエスト
        ↓
Notion「投資アイデア」へ追加（重複防止）→ 受信箱に「処理済み／該当なし」を書き戻し
```

- 受信箱を先に処理し、残った無料枠で監視ソースを回します。
- 無料枠を超えないよう、1回の実行で使うGeminiリクエスト数（既定9回＝1日18回）と間隔（既定13秒）を制限しています。上限に達した分はカーソルを進めず次回に回すので、取りこぼしません。
- 監視リスト・カーソル・抽出結果はすべてNotionに置きます。このリポジトリはpublicで、Actionsのログも公開されるため、リポジトリへのcommitやログへの内容出力は行いません（ログは件数のみ）。
- 1ソースが失敗しても他は続行し、失敗ソースのカーソルは進めません。失敗があれば `SLACK_WEBHOOK_SYSTEM` に件数とHTTPステータスだけを通知します。

## Xの扱い（追加料金なしの場合）

X APIは2026年に無料枠がなくなり従量課金のみになったため、標準構成ではXの自動巡回はしません。代わりに**アイデア受信箱**を使います。

- 普段Xを見ていて「これは」と思った投稿を、共有メニューからNotionの「アイデア受信箱」に保存する（URLだけでよい。気づきを「メモ」に書くとそれも判断材料になる）
- 次回の巡回で、X公式のoEmbedエンドポイント（埋め込み表示用に公開されている、認証不要の仕組み）から本文を取り、同じ基準で整理します
- 非公開アカウントや削除済みの投稿は取得できず「取得失敗」になります。長文投稿は途中までしか取れない場合があります（気になる部分はメモに貼ると確実）

Xのウェブ版を自動で巡回する方式は、利用規約でスクレイピングが禁止されていること、アカウント停止のリスク、ボット対策の強さから採っていません。

予算をかけてXも自動巡回したくなったら、`X_BEARER_TOKEN` を設定すると「監視ソース」のX／X検索が動きます（後述のコスト参照）。

## 事前準備

### 1. Notion

「SNS投資アイデア監視」ページの下に、以下の3つのデータベースを作成済みです。

| DB | data source ID |
|---|---|
| 監視ソース | `c6f327af-82b0-42b2-9b17-5253869121cf` |
| 投資アイデア | `ca344f15-4918-441c-b5f1-9d1b466c3459` |
| アイデア受信箱 | `a60ee042-d0e4-4448-8d9c-ca21491f1c40` |

1. https://www.notion.so/profile/integrations で内部インテグレーションを作成し、トークンを控える（機能: コンテンツの読み取り・更新・挿入）。
2. 「SNS投資アイデア監視」ページ右上の「…」→「接続」から、そのインテグレーションを追加する（子DBにも継承されます）。
3. 「監視ソース」にYouTubeチャンネルを1行ずつ追加し、「有効」にチェックする。
   - YouTube: プラットフォーム=YouTube、ハンドル=`UC`で始まるチャンネルID（チャンネルページの「概要」→「チャンネルを共有」→「チャンネルIDをコピー」）
   - X（有料オプション）: プラットフォーム=X、ハンドル=@なしユーザー名
   - X検索（有料オプション）: プラットフォーム=X検索、ハンドル=検索クエリ（例: `TOPIX 除外 リバランス`）
   - 「内部ID」「カーソル」「最終取得」はシステムが書き込みます。
4. スマホのNotionアプリで「アイデア受信箱」を開けるようにしておく。Xアプリの共有→Notion→保存先に「アイデア受信箱」を選べば1行追加されます。

### 2. Gemini APIキー（無料）

https://aistudio.google.com でAPIキーを発行します。請求先アカウントを紐づけなければ無料枠のまま使えます（ChatGPT Plus・Claude Pro・Gemini Proなどのアプリ契約にはAPI利用分は含まれないので、別途このキーが必要です）。

- 無料枠の上限はプロジェクトごとにAI Studioに表示されます。表示された1日あたりの回数に合わせて `IDEA_GEMINI_MAX_REQUESTS`（1回の実行あたり）を調整してください。1日2回実行なので、日次上限の半分弱が目安です。
- 無料枠では、送った内容（公開動画・公開投稿・受信箱のメモ）がGoogleの製品改善に使われる場合があります。受信箱のメモに個人的な情報は書かないでください。

### 3. GitHub（Settings → Secrets and variables → Actions）

Secrets:

| 名前 | 内容 |
|---|---|
| `NOTION_TOKEN` | Notionインテグレーションのトークン（必須） |
| `GEMINI_API_KEY` | Google AI StudioのAPIキー（必須） |
| `IDEA_HOLDINGS` | 保有銘柄。例 `285A:キオクシア,6857:アドバンテスト`（任意） |
| `X_BEARER_TOKEN` | XのBearer Token（有料オプション） |
| `ANTHROPIC_API_KEY` | Claudeで抽出したい場合（有料オプション） |

Variables:

| 名前 | 値 |
|---|---|
| `IDEA_WATCH_ENABLED` | `true`（これが無いとscheduleでも動きません） |
| `IDEA_SOURCES_DATA_SOURCE_ID` | `c6f327af-82b0-42b2-9b17-5253869121cf` |
| `IDEA_IDEAS_DATA_SOURCE_ID` | `ca344f15-4918-441c-b5f1-9d1b466c3459` |
| `IDEA_INBOX_DATA_SOURCE_ID` | `a60ee042-d0e4-4448-8d9c-ca21491f1c40` |
| `IDEA_GEMINI_MAX_REQUESTS` | 任意。1回の実行で使うGeminiリクエスト数（既定9） |
| `IDEA_GEMINI_MODEL` | 任意。既定 `gemini-3.8-flash`（無料枠のあるFlash系を指定） |
| `IDEA_LLM` | 任意。`claude` にするとClaude APIで抽出（有料） |

設定後、Actionsから `idea_watch` を手動実行（Run workflow）して、Notionに行が入ることを確認します。

## コストの目安

- **標準構成**: 0円。Gemini API無料枠、GitHub Actions（publicリポジトリは無料）、Notion、X oEmbed、YouTube RSS。
- **Gemini無料枠の消費**: 動画1本＝1リクエスト、テキスト20件＝1リクエスト。既定設定なら1日最大18リクエストで、動画なら1日18本程度が上限です。YouTube URL入力は2026年10月時点でプレビュー扱いで、条件は今後変わる可能性があります。
- **X API（任意）**: 投稿の読み取り1件ごとに約$0.005。30アカウント×1日平均5投稿なら月約$23。
- **Claude API（任意）**: `IDEA_LLM=claude` のときのみ。

## ローカル実行

```sh
# .env などで上記の環境変数を設定したうえで
.venv/bin/python -m src.run_ideas --dry-run   # 書き込まずに抽出結果を表示
.venv/bin/python -m src.run_ideas             # Notionへ書き込み
```

`--dry-run` は抽出内容を標準出力に出すため、ローカル専用です（Actionsでは使わない）。

## 既知の制約

- 1回の巡回で1チャンネルあたり最新3本（`IDEA_YT_MAX_VIDEOS_PER_SOURCE`）まで。
- 初回（カーソル未設定）は直近24時間（`IDEA_INITIAL_LOOKBACK_HOURS`）だけを対象にします。
- Geminiが読めるのは公開動画のみです。数時間の長いライブ配信は失敗することがあります。
- 抽出はAIによる整理です。発信者の主張の整理であり、採用前に過去の同種事例で検証し、日程・空売り可否は開示や証券会社で確認してください。
